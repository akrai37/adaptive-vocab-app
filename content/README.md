# Content

`words.json` is the word list: 143 words in 12 groups, each with a picture
and a short fact for children, in English and Spanish.

## Word shape

```json
{ "id": "cat", "category": "animals", "emoji": "🐈", "image": "images/cat.png",
  "text": { "en": "cat", "es": "el gato" },
  "fact": { "en": "A cat says meow.", "es": "El gato dice miau." },
  "audio": { "en": null, "es": null } }
```

- `id` never changes. The answer log refers to words by `id`, so it must stay
  stable when languages are added.
- `text`, `fact` and `audio` are keyed by language. Spanish words include
  their article. Group names per language are in `categoryNames`. Adding
  another language means adding entries here and screen text in
  `lib/l10n.dart`.
- `image` is the picture file under `content/`. `emoji` is a fallback if the
  file is missing.
- `fact` is one short sentence shown on the card and read aloud after the
  word. Keep it under 60 characters and true.
- `audio: null` means use the device's text-to-speech until a recording exists.

## How words were picked

Look-alike pictures in the same group were left out on purpose (e.g. squid
vs octopus, taxi vs car, banjo vs guitar), since same-group choices are the
"hard" questions.

- Concrete nouns that one picture can show without ambiguity.
- Short and common, so early readers can learn to recognise them.
- Each category has look-alike or related words (apple / orange / grape,
  eye / ear / nose). Same-category distractors make a hard quiz, and
  cross-category distractors make an easy one.

## Sources

- **Images:** Google Noto Emoji, 512 px PNGs from
  https://github.com/googlefonts/noto-emoji (`2D/png/512`), Apache License 2.0.
  Bundled in `images/` so the app works offline.
- **Audio:** device text-to-speech for v1. Record a real voice later if needed.

## Spanish

Latin American Spanish, generated by `tool/add_spanish.py`. Where countries
differ, the Mexican word was chosen (papalote for kite, catarina for
ladybug); the alternatives are listed in `spanish_review.csv` for review by a
native speaker.
