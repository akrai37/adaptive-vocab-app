# Development

## Run and test

```sh
flutter pub get
flutter test             # unit and widget tests
flutter analyze
flutter run -d chrome    # debug run
```

## Production build

Build and serve with caching turned off, then open http://localhost:8081:

```sh
sh tool/build_web.sh
python3 tool/serve_web.py
```

`build_web.sh` stamps the build time (shown bottom right of the home screen)
and gives the compiled code a new URL on every build, so a reload always
picks up the latest version. Avoid `python3 -m http.server`: it sends no
cache headers, and Chrome can keep serving an old `main.dart.js`.

`tool/screenshot.mjs` drives headless Chrome to capture screens, e.g.
`node tool/screenshot.mjs http://localhost:8081 out.png 9000 "483,275"`.

## Layout

| Path | Contents |
| --- | --- |
| `lib/vocab_game.dart` | The whole game as one widget; `lib/main.dart` runs it standalone |
| `lib/logic/` | Pure functions, no storage: `stats.dart` (answer log → Leitner boxes), `selector.dart` (next word and wrong options), `scoring.dart`, `explain.dart` (demo-mode notes) |
| `lib/data/` | `Session` (connects the engine to storage), `AnswerLog`, `RoundLog`, `WordRepository`, `Speaker`, `database.dart` (schema and migrations) |
| `lib/models/` | `Word`, `Answer`, `Activity`, `RoundResult`, `NewBest` |
| `lib/screens/` | Home → game picker → Cards, Find it, Bubble Pop, Flip & Match → round done; teacher screen |
| `lib/l10n.dart` | Languages and every on-screen text for children |
| `lib/config.dart` | Teacher passcode, round length, game timing |
| `lib/theme.dart` | Colours, Fredoka font, shared tiles |
| `content/` | `words.json`, pictures, content notes |
| `tool/` | Build, serve, screenshot and content scripts |

The teacher passcode is `1234` (`lib/config.dart`).

## Database

SQLite, schema version 4 (`lib/data/database.dart`). Migrations run
automatically on open, so existing data is kept when the schema changes.

## Editing content

Words live in `content/words.json` (see `content/README.md`). Spanish words
and facts are generated by `tool/add_spanish.py`, which also writes
`content/spanish_review.csv` for a native speaker to check. To apply
corrections, edit the table in the script and run it again:

```sh
python3 tool/add_spanish.py
```
